# קיצורי השעון

הדף `watch/index.html` מציג כרטיס הורדה לכל קיצור. כפתור «הורד קיצור» נדלק רק כשיש קישור iCloud בשדה המתאים בתוך `ICLOUD_LINKS` באותו דף. שדה ריק משאיר את הכיתוב «קישור ההורדה יתווסף בקרוב».

אחרי שמעתיקים קישור, מדביקים אותו בין המירכאות של השדה, שומרים, ומעלים את האתר.

| שדה | קיצור |
| --- | --- |
| `asher` | אשר יצר |
| `borei` | בורא נפשות |
| `meein` | מעין שלוש |
| `zmanim` | זמני היום |
| `menu` | שעון תפילה, התפריט |

## שעון תפילה, התפריט

1. פותחים את אפליקציית הקיצורים.
2. לוחצים על + ליצירת קיצור חדש.
3. נותנים לו את השם «שעון תפילה».
4. מוסיפים את הפעולה «בחר מתפריט» (Choose from Menu).
5. ארבעה פריטים, אחד בכל שורה: אשר יצר, בורא נפשות, מעין שלוש, זמני היום.
6. מתחת ל«אשר יצר» מוסיפים «קבל תוכן של כתובת» (Get Contents of URL) עם הכתובת `https://idanatwork.github.io/LPs/watch/asher-yatzar.txt`, ואחר כך «הצג תוצאה» (Show Result).
7. מתחת ל«בורא נפשות» אותן שתי פעולות, עם `https://idanatwork.github.io/LPs/watch/borei-nefashot.txt`.
8. מתחת ל«מעין שלוש» אותן שתי פעולות, עם `https://idanatwork.github.io/LPs/watch/meein-shalosh.txt`.
9. מתחת ל«זמני היום»:
   - מוסיפים «עצב תאריך» (Format Date) על «תאריך נוכחי» (Current Date).
   - בפורמט המותאם רושמים `yyyy-MM-dd`.
   - מוסיפים «קבל תוכן של כתובת».
   - הכתובת מתחילה ב־`https://idanatwork.github.io/LPs/watch/zmanim/`.
   - מיד אחרי הלוכסן האחרון מניחים את משתנה התאריך המעוצב, ומיד אחריו `.txt`.
   - ביום 14.11.2026 הכתובת המלאה היא `https://idanatwork.github.io/LPs/watch/zmanim/2026-11-14.txt`. התאריך מתחלף לבד בכל יום.
   - אחרי זה «הצג תוצאה».
10. לוחצים על שם הקיצור, או על ⓘ, ופותחים את הפרטים.
11. מסמנים «הצג בשעון» (Show on Apple Watch).
12. לוחצים על סמל השיתוף.
13. בוחרים «העתק קישור iCloud» (Copy iCloud Link).
14. מדביקים את הקישור בשדה `menu` בתוך `ICLOUD_LINKS` בקובץ `watch/index.html`.

## קיצור נפרד

1. קיצור חדש. השם לפי הטקסט, למשל «בורא נפשות» או «זמני היום».
2. «קבל תוכן של כתובת» עם הכתובת של אותו טקסט. לזמני היום משתמשים בתאריך המעוצב, כמו בענף שבסעיף הקודם.
3. «הצג תוצאה».
4. בפרטים מסמנים «הצג בשעון».
5. שיתוף, ואז «העתק קישור iCloud».
6. מדביקים בשדה המתאים: `meein` או `zmanim`. השדות `asher` ו־`borei` כבר מולאו.
