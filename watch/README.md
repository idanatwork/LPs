# קיצורי השעון

הדף `watch/index.html` מציג שלושה כרטיסי הורדה. כפתור «הורד קיצור» נדלק כשיש קישור iCloud בשדה המתאים בתוך `ICLOUD_LINKS`.

שלושת הקישורים כבר מולאים:

| שדה | קיצור |
| --- | --- |
| `asher` | אשר יצר |
| `borei` | בורא נפשות |
| `meein` | מעין שלוש |

קבצי הזמנים נשארים בשרת, בתיקייה `watch/zmanim/`, ואין להם כרטיס הורדה בדף.
